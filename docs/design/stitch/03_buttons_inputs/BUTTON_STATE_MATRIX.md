# Button State Matrix

Reference: `button-state-matrix.png`.

| Component | States |
| --- | --- |
| `GoldPrimaryButton` | default, pressed, disabled, loading, success, error |
| `ObsidianPrimaryButton` | default, pressed, disabled, loading, success, error |
| `IvorySecondaryButton` | default, pressed, disabled, loading, success, error |
| `PillChoiceButton` | unselected, selected, disabled |
| `IconCircleButton` | default, disabled, loading |
| `FloatingReactionButton` | default, disabled, loading |

Disabled buttons must explain why when the blocked action is player-facing.
Loading states must not resize the button.
