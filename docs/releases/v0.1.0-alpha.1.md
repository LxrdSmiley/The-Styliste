# The Styliste v0.1.0-alpha.1 — Draft Prerelease Notes

Status: **Unreleased draft**

This prerelease represents the Kingston Early Game repository-remediation
baseline. It is not Alpha-ready, Beta-ready, production-ready, or a public
mobile release.

## Included

- Early Game route containment for HQ, Atelier, Empire, Feed, and House.
- Kingston Founder Trial and Design Blueprint foundations.
- Stronger server-authority boundaries for design release, progression, idle
  settlement, rewards, and reviewed API projections.
- Append-only economy/reward evidence, idempotent idle receipts, RLS contract
  coverage, API inventory drift detection, and expanded CI gates.
- Session recovery that preserves linked identities and does not mistake a
  temporary network failure for an expired refresh token.
- Service-only design release with deterministic replay receipts and a
  per-design ledger idempotency key.
- A forward-only Kingston authority correction separating House Funds,
  lifetime gross/cost/net metrics, and idle-source rates; first-store opening
  preserves unrelated sources.
- Strict six-route Edge validation plus frozen starter-design catalog,
  session/ownership checks, count-safe scoring, and explicit Vex opt-in.
- Repository memory, changelog, release metadata, and guarded draft-prerelease
  workflow for the Android/iOS mobile target.

## Known blockers

- Supabase-only authentication changes require user-run Flutter and staging
  integration verification.
- Local Edge identity and four 20-way Kingston economic races pass. Historical
  SQL suites that require retired authenticated `public` access remain in
  conflict with the API-only boundary; hosted cross-player behavior remains
  unverified. Storage and Realtime are disabled for Kingston.
- The real repository `frontend-design` skill is unavailable, so the obsolete
  visual FTUE and incomplete Artisan/Architect/player-facing causal loops have
  not been corrected.
- Android/iOS release startup, signing, physical-device behavior,
  accessibility, and Galaxy A55-class performance are unobserved.
- Purchase sandbox, restore/refund, secret-history, and penetration evidence is
  incomplete or Blocked.
- Flutter Web, Chrome runtime, and Pages publication are deferred and outside
  this mobile prerelease.

## Disabled scope

Gala, territory, Casting, store trading, broad/private DMs, AR, marketplace,
ads, paid competitive multipliers, and other later-wave systems remain disabled.
